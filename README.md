# Municipal Assessor's Office Document Request Management System

A console-based system designed to streamline document request processing and improve service organization in a municipal assessor's office.

## Project Overview

This project presents a prototype of a document request management system designed to demonstrate how residents and office personnel may interact with a computerized request process. It is inspired by the general document-request procedures described in the Citizen's Charter of the Municipality of Manolo Fortich, but its workflows, sample data, and system operations are simulated and do not represent the actual office's complete procedures or records.

## Key Features

### Resident Functions
- View sample documents and requirements
- Submit simulated document requests
- Book and cancel appointments
- Monitor request statuses and staff instructions
- View personal requests and appointments

### Staff Functions
- Record and manage simulated document requests
- Generate reference numbers
- Search and monitor requests
- Verify requirements within the prototype
- Update request statuses
- Access a request monitoring summary
  
## Documents Covered

- Certified True Copy of Tax Declaration
- Certification of Property Ownership
- Tax Clearance
  
## Technologies Used

- Python
- Visual Studio Code
- Python Built-in Functions and Data Structures
  
## Limitations

This project is an academic prototype. Its workflows, sample information, requirements, appointment schedules, and other data are simulated for demonstration purposes and may not reflect the actual procedures or records of a Municipal Assessor's Office.

The application stores account, request, and appointment information temporarily in program memory. Data is not retained after the program terminates.

The system does not perform actual property assessments, official document verification or approval, payment processing, or document release. These activities remain outside the scope of the prototype.
